# Portafolio · Erik Tovar

🌐 **Sitio en línea:** https://elkiko123.github.io/

Portafolio personal de **Erik Tovar Carreón**, estudiante de Ingeniería en Sistemas Computacionales.

Sitio estático con proyectos de escritorio, web, móvil, IA, 3D, bases de datos, redes y ciberseguridad. Incluye tema claro/oscuro, animaciones, filtros por categoría y galerías con lightbox.

3. Automatización administrativa (HTML · CSS · JS · MySQL)
4. Cubo de Rubik 3D (C# · OpenGL)
5. Serenity · ansiedad social (Flutter · Supabase · IA)
6. Vehículo eléctrico con Arduino (Arduino · Electrónica · Bluetooth)
7. FitTrack AI (Flutter · Supabase · IA · GPS)
8. Laboratorio de cómputo (Hardware · Redes · Soporte técnico)
9. Cableado de red · Educación a Distancia (Redes · Infraestructura TI)
10. Laboratorios de ciberseguridad (Kali Linux · Windows Server · Nmap · Wireshark)
11. Red segmentada para clínica médica (Packet Tracer · VLANs · ACLs · AutoCAD)
