# Portafolio · Erik Tovar

Portafolio personal de **Erik Tovar Carreón**, estudiante de Ingeniería en Sistemas Computacionales.

Sitio estático con proyectos de escritorio, web, móvil, IA, 3D y bases de datos. Incluye tema claro/oscuro, animaciones, filtros por categoría y galerías con lightbox.

## Proyectos

- Gestión de inventarios (C# · Access)
- Base de datos para cine (PostgreSQL · Ubuntu Server)
- Automatización administrativa (HTML · CSS · JS · MySQL)
- Cubo de Rubik 3D (C# · OpenGL)
- Serenity · ansiedad social (Flutter · Supabase · IA)
- Control de carro electrónico (Flutter · Arduino)
- FitTrack AI (Flutter · Supabase · IA · GPS)

## Estructura

- `index.html` — página principal
- `pages/` — páginas de cada proyecto
- `css/` — estilos del sistema visual Auros
- `js/` — animaciones, filtros y lightboxes
- `img/` — capturas e imágenes de los proyectos
